Detailed Description

Binary file output class.

This class is used to write data to a binary file. The data in the file is big-endian. If the host nachine is little-endian, the data is byte-swapped. Output is done from the primary node only.

Files need to be opened before any of the write methods are used

The write methods are also wrapped by externally defined functions and << operators,
